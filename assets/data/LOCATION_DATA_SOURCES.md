# Location data sources

The bundled Pakistan location catalogue is assembled from:

- Pakistan administrative divisions (provinces, districts, tehsils): Open Admin Data, CC BY 4.0. Source: https://github.com/open-admin-data/pakistan-administrative-divisions
- Pakistan city and sub-area suggestions: pakistan-location-info-system, MIT License. Source: https://github.com/salmannaeem112215/pakistan-location-info-system

The data is provided as suggestions, not as a legal or authoritative postal-address registry. Admins can add, correct, and import further location entries through Talib-2.0's Location Catalog.
